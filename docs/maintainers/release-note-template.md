# Release note template

Use this template only after the release checklist is satisfied. Replace all placeholders and remove inapplicable sections with an explanation.

## Release identity

- Version / research milestone:
- Exact public commit and tag:
- Intel XNU source revision:

- Date:
- Release classification (research milestone or product release):

## Highlights

Describe completed and integrated work. Link the corresponding commits and evidence.

## Supported and tested configurations

List the CPU, host kernel, firmware where applicable, execution mode, and observed boundary for each tested combination. Identify untested configurations separately.

## Installation and recovery

Link the verified procedures for this exact release. Document prerequisites, known risks, recovery and removal. Do not reuse standalone instructions as hosted installation instructions.

## Changes and fixes

Group changes by subsystem. Include important regressions resolved and known limitations.

## Distribution

List available artifacts, SHA-256 checksums, corresponding source revisions and applicable licenses. Identify external dependencies and their lawful acquisition separately.

## Credits

Preserve upstream attribution and third-party acknowledgements.

## Verification

Link reviewed test results, the compatibility matrix and the release checklist. Explain excluded functionality and remaining qualification gates.
